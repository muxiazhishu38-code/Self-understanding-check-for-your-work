# 仕事の自己理解チェック

社内向けの「自己理解」を目的とした簡単なチェックツールです。
10個の質問に答えると、今の仕事への向き合い方を整理した結果が表示されます。

> **⚠️ 大切なこと**
> - このツールは **社内向けの自己理解用** です。
> - 結果は **評価や査定には一切使用しません**。

---

## 1. 使い方（利用する人向け）

1. `index.html` をブラウザで開きます。
2. **年代**を選びます（20代／30代／40代／50代／60代以上）。
3. **全10問**に回答します（各問、5段階から1つ選択）。
4. 一番下の **「結果を見る」** ボタンを押します。

### 未回答があると結果は出ません

未回答の設問が1つでもあると、結果は表示されず、
**未回答の設問が赤く表示され、下部にメッセージ**が出ます。
すべて回答してから、もう一度「結果を見る」を押してください。

---

## 2. ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（見た目・レイアウト） |
| `script.js` | 動き（回答の集計・結果の表示） |
| `questions.csv` | 設問の一覧 |
| `choices.csv` | 選択肢と点数 |
| `results.csv` | 結果（判定パターンと説明文） |
| `README.md` | この説明書 |

> プログラムを動かすには、**同じフォルダにこれらのファイルを置く**必要があります。
> `index.html` がデータ（CSV）を読み込んで表示します。

---

## 3. 編集のしかた（内容を変えたい人向け）

CSVファイルは **Excelやメモ帳で開いて編集**できます。編集後は保存するだけでOKです。

### 3-1. 設問を変える：`questions.csv`

| 列 | 意味 | 例 |
|---|---|---|
| `qid` | 設問番号 | `1` |
| `question` | 質問文 | `今の仕事は、自分にとって「なんとか続けられる」と感じている` |
| `scale` | 選択肢の種類（`choices.csv` と対応） | `agree` |
| `scoreType` | 集計の分類（A/B/C/D） | `A` |

- ヘッダー行（1行目）は消さないでください。
- 設問を増やすときは、同じ形で行を追加します。

### 3-2. 選択肢や点数を変える：`choices.csv`

| 列 | 意味 | 例 |
|---|---|---|
| `scale` | 選択肢の種類（`questions.csv` と対応） | `agree` |
| `label` | 表示する文言 | `とてもあてはまる` |
| `point` | 点数（数値） | `5` |

### 3-3. 結果（判定）を変える：`results.csv`

| 列 | 意味 |
|---|---|
| `age` | 対象の年代区分（`under40` / `40s` / `50s`） |
| `a_min` 〜 `d_max` | 各分類（A〜D）の点数の範囲（空欄は「制限なし」） |
| `title` | 結果の見出し |
| `description` | 結果の説明文 |

**年代の対応表**（画面の選択と `age` の関係）

| 画面での選択 | `results.csv` の `age` |
|---|---|
| 20代・30代 | `under40` |
| 40代 | `40s` |
| 50代・60代以上 | `50s` |

> 点数は、選んだ選択肢の `point` を分類（A〜D）ごとに合計して判定します。
> 各分類の設問数は、A=3問、B=3問、C=2問、D=2問です。

## 4. CSVを編集するときの注意点（重要）

守らないと、**表示が崩れたり結果がおかしくなったり**します。

1. **1行 ＝ 1件**。行の途中で改行しないでください。
2. **文章の中に半角カンマ `,` を使いたいときは、文章全体を `"`（半角の二重引用符）でくくってください。**
   - OK（半角カンマを使う場合）: `5,"人を気にする, すごく気にする",agree,B`
   - OK（読点を使う場合・くくり不要）: `5,人を気にする、すごく気にする,agree,B`
   - NG: `5,人を気にする, すごく気にする,agree,B` ← 半角カンマで列がズレます
3. 保存するときは **文字コードを「UTF-8」** にしてください（Excelから保存する場合は特に注意）。
4. ヘッダー行（1行目）は消さないでください。

## 5. 動作確認の方法（手元で試す）

`index.html` をダブルクリックして開くと、データ（CSV）が読み込めず正しく表示されないことがあります。
その場合は、次のように配信（サーバーを立てる）してから確認します。
（プログラミングの知識がなくても、コマンドを1回コピー＆実行するだけでOKです）

```bash
# このフォルダ（READMEがある場所）で実行
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/index.html` を開きます。

## 6. 不具合が出たら

**変更を元に戻してください**（これが最も安全な対処です）。

- GitHubの画面から、該当のコミットやプルリクエストを「Revert（元に戻す）」します。
- 直前に戻すには、変更をコミットする前の状態に戻します。

> 心当たりがある場合は、**最後に編集したCSVの内容**（特に半角カンマ・改行・文字コード）を確認してください。

## 7. よくある質問

**Q. 結果が「条件に一致する結果が見つかりませんでした」と出る。**
A. `results.csv` の点数範囲（`a_min`〜`d_max`）に、条件が当てはまらない可能性があります。年代や範囲の設定を確認してください。

**Q. 質問が正しく表示されない／別の文章になる。**
A. `questions.csv` の編集で、文章に半角カンマ `,` を入れて列がズレている可能性があります（→ 4. の注意点）。

**Q. 何も表示されない。**
A. `index.html` と同じフォルダにCSVがあるか、そして「5. 動作確認の方法」で配信しているかを確認してください。
